# Inventory-MIS-Dashboard-

The organization faced challenges in monitoring inventory stock levels, warehouse performance, damaged products, and supplier efficiency across multiple locations. Manual inventory tracking created delays in identifying low-stock products, inventory movement trends, and operational inefficiencies.

The objective of this project was to build an interactive Inventory MIS Dashboard in Excel for inventory monitoring, warehouse analysis, stock tracking, and operational reporting.

 Analysis Performed

* Analyzed inventory quantity across products and warehouses
* Monitored inventory value across different product categories
* Identified low-stock and high-stock inventory products
* Evaluated supplier performance using supplier ratings
* Tracked damaged and returned inventory units
* Analyzed warehouse-wise stock distribution
* Evaluated category-wise inventory contribution and stock movement trends

 Dashboard Output / Insights

* Improved visibility of inventory operations across warehouses
* Helped identify low-stock products requiring immediate restocking
* Enabled better warehouse-level inventory monitoring
* Improved supplier performance tracking and reporting
* Supported inventory planning and operational decision-making using Excel dashboards
* Reduced manual reporting effort through automated pivot-based reporting


 Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Conditional Formatting
* Dashboard Design
* Data Cleaning & Formatting
